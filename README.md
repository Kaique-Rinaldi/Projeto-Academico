Jogo da Cobrinha em Java

Projeto acadêmico desenvolvido durante a graduação em Engenharia de Software para aplicação prática de conceitos de Programação Orientada a Objetos utilizando Java.

Sobre o projeto:

O projeto consiste em uma versão do clássico Jogo da Cobrinha executada no terminal.

O jogador controla a cobra utilizando as teclas:

`W` - Cima
`S` - Baixo
`A` - Esquerda
`D` - Direita
`Q` - Sair

A cobra pode se movimentar pelo tabuleiro, coletar alimentos, aumentar seu tamanho e acumular pontos.

Durante o desenvolvimento foram aplicados conceitos como:

- Programação Orientada a Objetos
- Classes e objetos
- Atributos e métodos
- Construtores
- ArrayList
- Estruturas condicionais
- Estruturas de repetição
- Scanner
- Random
- Organização do código em diferentes classes
- Lógica de movimentação
- Detecção de colisões
- Controle de pontuação
